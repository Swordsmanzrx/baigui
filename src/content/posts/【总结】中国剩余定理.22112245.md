### 中国剩余定理

大致意思就是:

$\left\{\begin{matrix}x\equiv a_1(\bmod m_1)  \\x\equiv a_2(\bmod m_2) \\\dots \\x\equiv a_n(\bmod m_n)\end{matrix}\right.$

然后 $m_i$ 是相互互质的，然后要求的是 $x$。

这是一个同余方程组，我们可以用中国剩余定理去解决。

对于中国剩余定理就是一个结论，即 $x=\sum_{i=1}^{n}M_it_ia_i$。

其中令 $m=\prod^n_{i=1}m_i,M_i=\frac{m}{m_i}$，至于 $t_i$ 是 $M_it_i\equiv 1(\bmod m_i)$。

证明：

对于第 $i$ 个方程 $x\equiv a_i(\bmod m_i)$，因为对于 $j\ne i$ 来说，$M_j\bmod m_i$ 一定等于0，所以 $\sum_{i=1}^{n}M_it_ia_i\bmod m_i$ 等价于 $M_it_ia_i \bmod m_i$。

因为 $M_it_i \bmod m_i=1$，所以 $\sum_{i=1}^{n}M_it_ia_i\bmod m_i=a_i\bmod m_i$。 

所以 $\sum_{i=1}^{n}M_it_ia_i\equiv a_i(\bmod m_i)$。

证毕。

代码：

```
ll crt(){
	ll m=1,ans=0;
	for(ll i=1;i<=n;i++)m*=b[i];
	for(ll i=1;i<=n;i++){
		M[i]=m/b[i];
		exgcd(M[i],m[i]);
		ans=(ans+M[i]*x*a[i]);
	}
	return ans;
}
```

这就是最基础的 CRT 的代码，如果需要求最小值那么对 $m$ 取余，如果会爆 long long 记得开 __int128。

### 扩展中国剩余定理

虽然叫扩展中国剩余定理但和中国剩余定理几乎没关系，就是题目类似罢了。

扩展在没有 $m_i$ 相互互质这个条件了。

但是无妨。

假设对于前 $k-1$ 个方程有解 $x$，并且有 $m=lcm(m_1,m_2,m_3,\dots,m_{k-1})$。

那么考虑无论给 $x$ 加多少个 $m$，那么结果都可以满足前 $k-1$ 个方程，因为 $m\bmod m_i=0$。

所以前 $k-1$ 个方程的通解是 $x+pm,p\in Z$。

所以我们的前 $k$ 个方程的解 $x'$ 只要满足 $x+pm$ 的形式就是满足条件的。

所以带入 $x+pm\equiv a_k (\bmod m_k)$。

显然这是一个同余方程，$pm\equiv a_k-x(\bmod m_k)$。

接下来随便写写吧。

$$pm=(a_k-x)+qm_k$$

$$pm-qm_k=(a_k-x)$$

先求出 $pm-qm_i=\gcd(m,m_k)$ 的解 $p=x_0$。

然后 $\frac{x_0}{\gcd(m,m_k)}m-\frac{q}{gcd(m,m_k)}m_i=1$。

最后 $\frac{x_0(a_k-x)}{\gcd(m,m_k)}m-\frac{q(a_k-x)}{gcd(m,m_i)}m_i=(a_k-x)$。

所以 $\frac{x_0(a_k-x)}{\gcd(m,m_k)}m\equiv (a_k-x)(\bmod m_k)$。

所以前 $k$ 个方程的特解是 $\frac{x_0(a_k-x)}{\gcd(m,m_k)}+x$。

之后在递推到 $n$，就结束了。

```
void solve() {
	cin>>n;
	for(ll i=1; i<=n; i++)cin>>a[i]>>b[i];
	ll m=b[1];
	ll ans=a[1];
	for(ll i=2; i<=n; i++) {
		ll d=exgcd(m,b[i],x,y);
		ll c=(a[i]-ans%b[i]+b[i])%b[i];
		x = (__int128)x * (c/d) % (b[i]/d);
		x = (x % (b[i]/d) + (b[i]/d)) % (b[i]/d);
		ans=ans+(__int128)m*x;
		m=(__int128)m*b[i]/gcd(m,b[i]);
		ans=(ans%m+m)%m;
	}
	cout<<ans<<"\n";
}
```
